# Contributing

Thanks for helping! Bug reports, translations and pull requests are welcome.

## Reporting bugs
Use the issue templates. Please include Moodle and PHP versions, the AI provider, and whether the file is a text PDF, a scanned PDF or a DOCX. Never paste API keys.

## Pull requests
- Follow the [Moodle coding style](https://moodledev.io/general/development/policies/codingstyle) and keep the GPL header in every PHP file.
- Add or update PHPUnit tests (`tests/`) for PHP changes.
- New user-facing text goes in `lang/en/block_aipdfassistant.php`. The EN/AR/FR packs are generated by `tools/langgen.py`: edit that file and regenerate rather than editing the lang files by hand.
- JavaScript lives in `amd/src/`. Rebuild `amd/build/` with `grunt amd` in a Moodle checkout.
- Mention the change in `CHANGELOG.md`.

## Translations
Native-speaker corrections for Arabic and French are especially welcome, as are new languages.
