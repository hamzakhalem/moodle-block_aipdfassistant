# Security policy

## Reporting a vulnerability
Please **do not** open a public issue for a security problem. Contact the maintainer privately through https://hamzakhalem.pages.dev (or GitHub's private vulnerability reporting, *Security > Report a vulnerability*, if enabled on this repository). Include the plugin version, Moodle version and steps to reproduce.

You can expect an acknowledgement within a few days. Fixes are released as a new plugin version and noted in `CHANGELOG.md`.

## Scope
Of particular interest: reading of hostile PDF or Word files, exposure of API keys, access to another user's documents or cached answers, and prompt-injection that crosses a permission boundary.

## Supported versions
Only the latest release is supported.
